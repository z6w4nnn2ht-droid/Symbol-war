# Symbol War

这是一个以符号为主题的 HTML 网页游戏项目，当前仓库主要内容为单文件游戏：`符号大战.html`。

## 项目说明

- 项目类型：HTML 游戏
- 语言构成：HTML
- 运行方式：直接在浏览器中打开 `符号大战.html`

## 使用方法

1. 下载或克隆本仓库。
2. 在浏览器中打开 `符号大战.html`。
3. 按照页面提示开始游戏体验。

## 说明

本仓库目前以单文件方式提供，适合快速试玩和二次开发。如果你想扩展此项目，可以在现有 HTML 文件基础上添加样式、脚本和额外功能。
