# 符号大战

一款数学主题的俯视角生存冒险游戏，风格参考 florr.io。你控制一个身边环绕着卡片的小人，在弯曲的迷宫洞穴里击败 π、∑、∞ 这样的数学符号怪物，收集并合成稀有度越来越高的符号卡片，穿过传送门前往更危险的地图。

整个游戏是**一个独立的 HTML 文件**（`symbol-war.html`），不需要安装，也不依赖任何外部资源，用浏览器打开就能玩，电脑和手机都可以。

## 快速开始

1. 用浏览器打开 `symbol-war.html`。
2. 在主页输入名字，点「开始战斗」。
3. 移动、靠近怪物，你身边旋转的卡片会自动攻击它们。
4. 捡起怪物掉落的卡片，装备上去，变得更强。

## 操作

| 操作 | 电脑 | 手机 |
|---|---|---|
| 移动 | WASD 或方向键 | 在屏幕上拖动 |
| 背包 | B 键，或左侧「背包」按钮 | 左侧「背包」按钮 |
| 地图 | M 键（放大 / 缩小小地图） | 左侧「地图」按钮 |
| 切换备用栏 | 数字键 1–9 | 点两个栏位互换 |

**装备卡片**：打开背包，点击背包里的卡片，它会放进装备栏。点击已装备的栏位，卡片会放回背包。不开背包时，依次点击两个栏位可以互换。

## 界面

- **主页**：绿色草地背景，上面漂浮着怪物和卡片，中间是彩色大标题、名字输入框和「开始战斗」按钮。有存档时按钮会变成「继续游戏」，并显示存档等级和所在地图。
- **左上角**：名字和地图名，下面是黄色的经验条（里面写着 Lv.几）和绿色的血条。中毒时屏幕边缘会泛起紫色光晕，中毒时间越长越浓。
- **左侧按钮栏**：七个彩色的方形按钮——背包、合成、成就、天赋、皮肤、图鉴、地图。有天赋点可花时，天赋按钮上会出现红点。
- **底部**：装备栏，上面一排是主栏，下面一排是较小的备用栏。
- **视野**：比较开阔，能同时看到较大范围的地图。

## 玩法系统

**地图与迷宫**
- 一共 8 张地图：花园、沙漠、洞窟、深渊、冰原、熔岩、虚空、地狱蚁穴，用传送门相连，难度依次升高。走进传送门时屏幕会渐暗渐亮，到达后顶部会显示地图名、难度和怪物品质范围。
- 每张地图都是**弯曲的迷宫**：通道宽，石壁厚，边缘是平滑的曲线。越靠后的地图格子越多、捷径越少，路线绕得越远。
- 每张图里有 2 到 6 个很大的圆形斗室，里面立着几根石柱，可以躲在后面。
- 地图每次进入都会重新随机生成，所有传送门都保证走得到。
- 地图上还有毒池（前期）、岩浆（后期）、友方玩家（会帮你打怪）、敌对玩家，以及每隔一段时间出现的怪潮。

**怪物**
- 28 种数学符号怪物，各有特点：会瞬移（不能穿墙）、会冲刺、带毒、死后分裂；还有会朝你喷射式子（如 k²、Ψ(x,t)）的远程怪，以及 Boss。
- 怪物用 A* 寻路追你，碰到你会被弹开、往后退一下再冲回来，不会一直贴在身上。
- 怪物品质分 10 档（普通到唯一）。每张地图所有品质都可能出现，但各有常见区间，同一张图里不同区域的强弱也不同，离出生点越远越强。

**卡片（装备）**
- 62 种卡片：基础运算（+ − × ÷ ……）、微积分与逻辑符号，以及 22 种怪物卡。
- 怪物主要掉落自己符号的卡片，Boss 必掉。
- 每张卡片的效果都对应它的数学含义，比如积分会累积伤害、极限会把怪物拉向你、垂直会把怪物击飞。把鼠标移到卡片上可以看到名称、稀有度和作用。
- 部分卡片只有放在上排主栏才生效（如交集、空集、各种召唤卡）。
- 稀有度每升一档，装备伤害乘以 1.5。

**合成**
- 点开「合成」页，点背包里的卡片放进圆圈，凑齐 5 个相同稀有度的同一种卡片，按「合成」。圈里的卡片会越转越快，最后出结果：成功得到高一档的卡片，失败会损失 1~4 张。
- 稀有度越高，成功率越低。

**成长**
- 击败怪物获得经验，等级最高 60，升级所需经验越来越多。游戏里不显示分数，只显示等级。
- 成就解锁后获得天赋点，可在天赋页升级各项能力（血量、移速、伤害、回血、护甲、幸运、拾取范围等，共 23 项）。
- 另有 64 个成就和一个图鉴，记录你见过的怪物和得到过的卡片。

**死亡**
- 倒下时画面变灰，你身上的卡片和碎片向四周飞散，随后出现「你死了」的界面：显示击杀者的符号卡片和名字（被毒、毒池、岩浆杀死时会显示对应的符号），以及你的等级。
- 点「回到主页」，再点「继续游戏」，会在当前地图的出生点复活。背包、装备、天赋都保留。

## 存档

- 进度保存在浏览器的 `localStorage` 里，每 5 秒以及死亡、切换页面时自动存档。名字单独保存。
- 游戏里没有重置存档的按钮。想重新开始，需要清除这个页面的浏览器存储数据。
- 换浏览器、换设备或用无痕模式，存档不会跟着走。

## 技术说明

- 纯 HTML5 Canvas + 原生 JavaScript，没有任何依赖库。
- 地图生成：先在格子上生成迷宫（深度优先 + 按地图序号递减的捷径比例），再打通几个大斗室，最后整体做平滑的扭曲，并把石壁轮廓平滑成曲线。碰撞按平滑后的轮廓计算。
- 怪物寻路用 A*，另有一套从玩家出发的距离场，用来判断怪物是否进入追击范围。
- 墙壁轮廓线按区块缓存，不用每帧重新计算。

## 已知情况

- 开发时用脚本模拟和渲染地图图片检查过游戏逻辑与地图形状，没有在真实浏览器里长时间试玩，数值（怪物血量、伤害、掉落、难度曲线）都是估的，可能需要根据实际手感调整。
- 左侧按钮的图标用的是系统自带的表情符号，不同设备上外观会略有不同。
- 墙壁每帧整块绘制，低端手机上可能会有点卡。
