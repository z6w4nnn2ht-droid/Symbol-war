# 符号大战

这是一个基于 HTML5 Canvas 的符号生存冒险游戏，玩家以“花瓣”与“数学符号”为核心进行战斗、探索与合成。游戏内容包括地图探索、符号怪物战斗、装备管理、合成升级和成就系统。

## 游戏简介

- 项目类型：浏览器单页游戏
- 运行方式：直接打开 `符号大战.html` 即可游玩
- 技术实现：纯 HTML + CSS + JavaScript
- 玩法核心：移动、射击、拾取、合成、升级、挑战更高难度地图

## 主要功能

- 以数学符号为主题的怪物与掉落物
- 多地图探索：花园、沙漠、洞窟、深渊、冰原、熔岩、虚空等
- 装备栏与备用栏管理
- 花瓣收集、升级与合成系统
- 成就和天赋树系统
- 本地存档（浏览器 localStorage）
- 单文件部署，几乎不需要额外环境

## 玩法说明

1. 打开 `符号大战.html`。
2. 在首页点击“继续游戏”或“开始游戏”。
3. 使用键盘 `WASD` / `方向键` 移动角色。
4. 攻击和收集符号“花瓣”，提升装备与战斗力。
5. 在背包中管理物品，点击“合成”进行花瓣升级。
6. 逐步探索不同地图，击败怪物、BOSS 和敌对玩家。

## 控制方式

- 移动：`WASD` / 方向键
- 背包：`B`
- 取消/关闭界面：`Esc`
- 切换大地图/缩略地图：`M`
- 选中装备栏快捷键：`1` - `9`
